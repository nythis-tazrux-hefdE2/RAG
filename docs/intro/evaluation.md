# 评测

读者：需要比较同一知识库检索配置的管理员。前置条件为已索引文档、可用的问答/Judge 模型及该知识库管理权限。

## 创建数据集

在知识库评估页上传 JSONL，或选择现有生成方式创建基准。生成依赖真实知识片段和模型；上传和生成之后都应检查题目、参考答案和来源是否有效。

## 运行与比较

新建评估时选择数据集与检索配置，等待逐题执行结束。结果保留现有 Recall/F1、LLM Judge 和综合分，可切换同一基准的运行记录比较结果，并下载 JSONL 数据集。不同配置的结果应关联相同数据集和知识文档状态。

失败题和缺失指标必须保留原语义，不能用成功题替代或把缺失值填零。评测不纳入问答耗时/Token 作为新评分维度；这些事实从 Dashboard 和 PG 执行明细查看。
