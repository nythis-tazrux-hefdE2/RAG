# 知识库与图谱

读者：需要导入文档、检索事实并核对来源的知识库管理员。知识库从 `/knowledge` 进入；普通用户在问答中使用后端授权的可见知识库。

## 文档生命周期

新建 Milvus 知识库后上传文件，上传只创建暂存对象。正式登记校验对象、内容 hash 与大小，后台作业完成解析、切分和索引后才进入可检索状态。详情页展示进度、失败原因、重试、取消、重解析和重索引入口。

重解析和重索引由文件 generation 与执行 owner 控制；活跃代发布前，未完成的新投影不能替换旧结果。删除先在权威状态中隐藏文件，再由 outbox 清理对象、向量和图投影。这些机制属于文件处理，不提供整库发布版本。

## 检索与来源

默认向量检索保持原路线；调试查询可选择 BM25、混合检索及重排。问答通过内部 Knowledge MCP 检索、定位文档、打开正文和图片。引用应核对文件、generation、片段及行范围，不能只看模型文字。

会话选择支持全部当前可访问知识库或明确列表。保存只影响后续提交，运行使用提交时冻结选择；每次知识调用再复核当前用户权限。撤权影响同一运行的下一次调用，不承诺撤回已经返回的内容。

## 图谱

在知识库详情锁定抽取配置，提交图构建，等待作业结束。图谱页读取实体、关系及来源，检索可启用 PPR 融合。是否存在真实图召回要从结果和持久投影核对，不能由开关已开启推断。
