# 文档解析参考

复杂 PDF 默认使用现有 MinerU 官方 API。可通过私有 `.env` 配置 `RAG_MINERU_API_KEY`，或在设置页填写 MinerU 官方 API 配置。环境变量在重建 API/worker 后生效；页面保存值依现有 options 缓存失效机制生效。

MinerU 支持的模型版本、OCR、表格和公式选项由解析引擎声明与设置 schema 拥有。RapidOCR 保留为已有可选引擎，其他既有本地引擎通过显式 profile 使用；默认不部署本地 GPU OCR 服务。

MD/TXT 使用已有文本路径；Office、表格和图片按支持扩展名选择现有引擎。解析产物包含 Markdown 和关联图片，通过本应用对象存储及受权读取接口访问。任务成功后仍需核对解析正文、表格、图片和索引；配置健康只说明凭据存在，不执行真实解析。

官方 API 会把所选文档发送至配置的 MinerU 服务。验收只使用新建合成资料。密钥缺失、额度或远端故障必须显示实际失败，不能静默换引擎冒充通过。
